NPR 7123.1 groups systems engineering into 17 common technical processes. This page records where each is
carried out in this project so reviewers can find the evidence.

## System design processes

| # | Process | Where it is done here |
|---|---|---|
| 1 | Stakeholder Expectations Definition | Concept of Operations page; Level 1 **Requirement** items |
| 2 | Technical Requirements Definition | **Requirement** items |
| 3 | Logical Decomposition | `derives_from` links between requirements |
| 4 | Design Solution Definition | Design pages; **Decision** items |

## Product realization processes

| # | Process | Where it is done here |
|---|---|---|
| 5 | Product Implementation | **Task** items |
| 6 | Product Integration | **Task** items; System Integration Review |
| 7 | Product Verification | **Verification activity** items linked with `verifies` |
| 8 | Product Validation | **Verification activity** items against the ConOps |
| 9 | Product Transition | System Acceptance Review; Operational Readiness Review |

| # | Process | Where it is done here |
