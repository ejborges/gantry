Open **About** from the account menu or the foot of the rail. The same statements are available **before signing in**, from the links beneath the sign-in form.

## About this installation

The first page says which version of Gantry your organization runs and lists its **components and add-ons**: for each, its name, version, date, a one-line summary and a description. It covers the server (which includes the API, the real-time connection and the MCP endpoint), the web application, this manual and every add-on that is installed, and it names the stores in use for files, search and caching. When you report a problem, quote the version shown here.

It also shows **how to get help**: the support contact your administrator entered.

## Statements

| Statement | What it tells you |
| --- | --- |
| **Privacy** | What personal data the installation holds about you and who can see it. |
| **Terms** | The conditions your organization sets for using the installation. |
| **Cookies** | Which cookies and browser storage are used, and for what. |
| **Data retention** | How long data is kept and how it is removed. |
| **Data security** | How data is protected. |

Each statement has two parts.

- **What your organization says**: text written by your administrators. If they have written nothing, the page says so plainly; it does not invent a policy on their behalf.
- **What the software does**: facts about Gantry itself that are true of every installation. For example: it sets one cookie, which keeps you signed in, and no advertising, analytics or tracking cookies; it loads no content from other sites; passwords, sessions and API tokens are stored only as hashes; every action is logged with who, what, when and from where; notifications in your inbox are kept for 90 days; and it sends nothing to its makers or to other parties, contacting other systems only where an administrator has set up an integration, a sign-in provider or a mail server.

The facts are part of the product and are the same in every installation of the same version. Your organization's own text is the place for everything specific to you: the lawful basis for processing, retention periods, whom to contact.

## Licenses

**Licenses** lists every piece of open-source software Gantry is built from: its name, version, license and where it comes from, for both the server (Rust libraries) and the web application (JavaScript libraries, including the charting libraries Chart.js, Apache ECharts, Plotly and D3). **Find a package or a license** narrows the list.

Gantry itself is open source under the Apache License 2.0.

## Error messages and help

**Error messages and help** lists every error page the application can show and what to do about each, with the support contact. See [When something goes wrong](troubleshooting.md#error-pages).
